# solrac-voice

The voice of [Solrac](https://github.com/cjus/solrac-chess), as a program of its own: it reads
text aloud (Kokoro) and turns speech into text (Parakeet), on this computer, and answers the
[Chess Node Protocol](https://github.com/cjus/chess-node-protocol)'s voice domain over its
standard input and output.

Work in progress: milestone M1b of Solrac (cjus/chessgui#98).
