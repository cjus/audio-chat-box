Parrot Service.

Speak, see what it heard, and hear it back — powered by audio-chat-box.

This is a speech round-trip, not an AI chatbot. Parakeet transcribes your English speech; Kokoro reads the words back. No language model or paid API is involved.

After transcription, the demo also generates the spoken version. Press Play below to hear it; your browser may block automatic playback.

Audio and text go to the container serving this page, not to an external speech API. This page stores neither in browser storage. Use the documented localhost-only Docker command; this demo is not a public multi-user service.

Microphone access requires http://localhost or HTTPS and your permission. Remote HTTP addresses will not work. The Docker image includes the speech models; see the repository's Docker demo guide for their licences.
